# Decisões de arquitetura (ADR)

Esta é a casa das ADRs a partir da **0017**, por consequência do
[ADR-0016](https://github.com/admddg/impuls-plataforma/blob/main/docs/adr/ADR-0016-um-banco-um-repositorio.md),
que definiu `admddg/impulshub-dashboard` como repositório único.

**ADR-0001 a ADR-0016 continuam em `admddg/impuls-plataforma`, em `docs/adr/`.**
Esse repositório é arquivo: não recebe código novo, mas as decisões antigas
continuam valendo e são a origem de boa parte do desenho atual. Não foram
movidas para cá porque mover 16 arquivos não deixa nenhuma decisão mais clara —
e o ponteiro resolve.
